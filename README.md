# homebrew-tap

A [Homebrew](https://brew.sh) tap for [`git-stk`](https://github.com/lararosekelley/git-stk).

```sh
brew install lararosekelley/tap/git-stk
```

The `Formula/` directory is generated automatically by [dist](https://opensource.axo.dev/cargo-dist/) on each `git-stk` release; it is not edited by hand.
